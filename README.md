# 💅 BeautyStart

Маленький сайт, где можно найти салон маникюра в Москве по станции метро
и посмотреть мастера.

---

## 🧐 Что это вообще?

Представь сайт-«поисковик» салонов красоты:

1. Пишешь название метро (например, **Выхино**).
2. Сайт показывает салоны рядом.
3. Жмёшь на салон → видишь мастера, цены и свободное время.

Вот и всё. Никакой магии.

---

## 📂 Что внутри (файлы)

| Файл | Зачем он |
|------|----------|
| `app.py` | Мозг сайта. Тут вся логика на Python (Flask). |
| `metro.txt` | Простой список станций метро Москвы. |
| `templates/index.html` | Главная страница (поиск салонов). |
| `templates/master.html` | Страница мастера (цены и запись). |

---

## 🚀 Как запустить

Нужен установленный **Python**.

1. Открой папку с проектом в терминале.
2. Установи Flask (один раз):

   ```bash
   pip install flask
   ```

3. Запусти сайт:

   ```bash
   python app.py
   ```

4. Открой в браузере: **http://127.0.0.1:5000**

Готово! 🎉 Чтобы выключить — нажми `Ctrl + C` в терминале.

## ✅ Что пока не доделано

- Кнопки времени записи **ничего не сохраняют** (запись «в разработке»).
- Все салоны ведут на **одного и того же** мастера.
- Данные о салонах хранятся прямо в коде, базы данных нет.
